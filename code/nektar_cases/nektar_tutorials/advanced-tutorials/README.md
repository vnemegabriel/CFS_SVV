# Advanced tutorials

This folder contains some more advanced tutorial notebooks, still based within
the Jupyter environment.

## Theory

- `theory-01-basics`: An overview of the background theory for spectral/$hp$
  element methods in a single 1D element.

## Solvers

- `compressible-solver-01-basics`: Setting up and running a basic session file
  for the compressible flow solver.
- `incns-solver-01-forcedVibration`: A moving-body problem using the incompressible
  Navier-Stokes solver.
- `incns-solver-02-ts-waves-stability`: Linear stability analysis of a
  Thomas-Schlichting wave problem.

## Pre-processing

- `nekmesh-01-cylinder`: Generate a 2D mesh of flow around a cylinder using
  `NekMesh`.
- `nekmesh-02-python-api`: A demonstration of the Nektar++ Python API to
  NekMesh.
