1. Governing equations and weak DG discretisation

1.1 Conservation form

The solver integrates the compressible Navier–Stokes equations in conservation form [DG 15.1.1, eq. 15.1]:

$$\frac{\partial\mathbf U}{\partial t}=\mathcal L(\mathbf U)=-\nabla\cdot\mathbf H,\qquad \mathbf H_i=\mathbf F_i(\mathbf U)-\mathbf G_i(\mathbf U,\nabla\mathbf U).$$

$\mathbf U$ is the vector of conserved variables. $\mathbf F_i$ is the inviscid flux in direction $i$. $\mathbf G_i$ is the viscous flux. In 2D [UG 9.1]:

$$\mathbf U=\begin{pmatrix}\rho\\ \rho u\\ \rho v\\ E\end{pmatrix},\quad \mathbf F_x=\begin{pmatrix}\rho u\\ \rho u^2+p\\ \rho uv\\ u(E+p)\end{pmatrix},\quad \mathbf F_y=\begin{pmatrix}\rho v\\ \rho uv\\ \rho v^2+p\\ v(E+p)\end{pmatrix},\quad p=(\gamma-1)\Big(E-\tfrac12\rho|\mathbf u|^2\Big).$$

$$\mathbf G_x=\begin{pmatrix}0\\ \tau_{xx}\\ \tau_{xy}\\ u\tau_{xx}+v\tau_{xy}+k\,\partial_xT\end{pmatrix},\qquad \tau_{ij}=\mu\Big(\partial_ju_i+\partial_iu_j-\tfrac23\delta_{ij}\nabla\cdot\mathbf u\Big).$$

For EulerCFE, $\mathbf G=0$. The variable names in the session file are rho, rhou, rhov, rhow, E [UG 9.3]. The equation of state is selectable (IdealGas, VanDerWaals, RedlichKwong, PengRobinson).

Why the solver uses this form

The form has four consequences in the solver.

1. Correct shocks. The equation is in divergence form and uses the conserved variables $\mathbf U=(\rho,\rho u,\rho v,E)$. The Lax–Wendroff theorem states that a conservative scheme, if it converges, converges to a weak solution. A weak solution satisfies the Rankine–Hugoniot conditions across a discontinuity:

$$s\,[\![\mathbf U]\!]=[\![\mathbf F\cdot\mathbf n]\!],$$

where $s$ is the shock speed and $[\![\cdot]\!]$ is the jump. Thus the position and the speed of the shock are correct. A non-conservative form (for example, in the primitive variables $\rho$, $u$, $p$) is equal for smooth flow, but at a shock it gives a different jump condition and an incorrect shock speed. The transonic NACA 0012 case has a shock, so this form is necessary.

2. Discrete conservation. Only the divergence form can be integrated by parts. This gives the weak DG form of Section 1.2, with a volume term $(\nabla\phi,\mathbf H)$ and a face term $\langle\phi,\hat H_n\rangle$. With $\phi=1$ the volume term is zero and the element balance contains only face fluxes. Adjacent elements use the same numerical flux. Thus mass, momentum and energy are conserved to round-off. K&S Section 10.1 uses the same property (cell averages and face fluxes).

3. One structure for all terms. $\mathbf H=\mathbf F-\mathbf G$ puts the inviscid and the viscous fluxes in the same form. Both use the same three operations: flux at the quadrature points (volume), numerical flux on the trace (Riemann solver for $\mathbf F$, LDG or IP for $\mathbf G$), and integration. Thus AdvectionWeakDG and DiffusionLDGNS have the same structure. Artificial viscosity and SVV enter as one more flux in $\mathbf G$.

4. Method of lines. The right side is one operator, $\partial_t\mathbf U=\mathcal L(\mathbf U)$. This separates space from time. $\mathcal L$ is the function that the time integrator calls (DoOdeRhs, registered with DefineOdeRhs). Thus any explicit or implicit scheme of LibUtilities advances the same spatial operator. The implicit solver uses the same $\mathcal L$ in the residual $\mathbf N(\mathbf u)=\mathbf u-\mathbf s-\Delta t\,a_{ii}\,\mathcal L(\mathbf u)$.

The conserved variables also set the boundary treatment: the boundary objects give the exterior state $\mathbf U^+$, and the Riemann solver returns a conservative flux.

1.2 From the strong form to the weak form

The domain $\Omega$ is divided into $N_e$ elements $\Omega^e$. On each element, the solution is a polynomial. The polynomials of adjacent elements are independent (Projection = DisContinuous). The continuous projection is not available in this solver [UG 9.3].

Step 1. Multiply (15.1) by a test function $\phi_p$ of element $e$ and integrate over $\Omega^e$:

$$\int_{\Omega^e}\phi_p\,\frac{\partial\mathbf U}{\partial t}\,d\Omega=-\int_{\Omega^e}\phi_p\,\nabla\cdot\mathbf H\,d\Omega .$$

Step 2. Integrate the right side by parts. Use $\phi\,\nabla\cdot\mathbf H=\nabla\cdot(\phi\mathbf H)-\nabla\phi\cdot\mathbf H$ and the divergence theorem:

$$\int_{\Omega^e}\phi_p\,\frac{\partial\mathbf U}{\partial t}\,d\Omega=\int_{\Omega^e}\nabla\phi_p\cdot\mathbf H\,d\Omega-\int_{\Gamma^e}\phi_p\,\mathbf H\cdot\mathbf n\,d\Gamma .$$

Step 3. On $\Gamma^e$ the solution has two values: the interior value $\mathbf U^-$ and the exterior value $\mathbf U^+$. Thus $\mathbf H\cdot\mathbf n$ is not defined. Replace it with a numerical flux $\hat H_n(\mathbf U^-,\mathbf U^+,\mathbf n)$ that both elements use. The result is the weak DG form [DG eq. 15.2] [KS 6.2.2, eq. 6.2.9]:

$$\boxed{\int_{\Omega^e}\phi_p\,\frac{\partial\mathbf U}{\partial t}\,d\Omega=\int_{\Omega^e}\nabla\phi_p\cdot\mathbf H\,d\Omega-\int_{\Gamma^e}\phi_p\,\hat H_n\,d\Gamma}$$

The inviscid part of $\hat H_n$ comes from a Riemann solver (UpwindType). The viscous part comes from the LDG or interior penalty method (DiffusionType) [DG 15.1.2] [KS 10.5.1.2].

Why this form is conservative (link to K&S Section 10.1)

Put $\phi=1$ in the weak form. The volume term is zero, because $\nabla 1=0$. The result is $\frac{d}{dt}\int_{\Omega^e}\mathbf U=-\int_{\Gamma^e}\hat H_n$. This is the finite-volume balance (10.1.3a) for the whole element. Two adjacent elements use the same $\hat H_n$ with opposite normals. Thus the inner fluxes cancel in the global sum. The staggered scheme of Section 10.1 gets conservation from the same property.

The difference is the unknown. In Section 10.1 the unknowns are $P$ cell averages and a reconstruction gives the polynomial. In DG the polynomial coefficients are the unknowns, so no reconstruction is necessary. A constant is in every modal basis of Nektar++ ($\phi_0+\phi_1=1$ for Modified_A), so the $\phi=1$ argument applies.

Strong form (equivalent; used by flux reconstruction)

Integrate the volume term by parts again. The result is

$$\int_{\Omega^e}\phi_p\,\frac{\partial\mathbf U}{\partial t}=-\int_{\Omega^e}\phi_p\,\nabla\cdot\mathbf H-\int_{\Gamma^e}\phi_p\,(\hat H_n-\mathbf H^-\cdot\mathbf n).$$

This form is equal to the weak form when the quadrature is exact. With inexact quadrature the two forms differ by aliasing terms. Flux reconstruction (FR) starts from this form. The User Guide states that only WeakDG is fully supported; other advection operators work only on quadrilaterals [UG 9.3].

1.3 Expansion and quadrature

Write the solution of element $e$ as $\mathbf U^\delta=\sum_q\mathbf u_q\phi_q(\mathbf x)$. Calculate all integrals with a quadrature rule: $N_Q$ points $\mathbf x_i$ with weights $w_i$ in the element, and $N_Q^\Gamma$ points on its boundary. $J_i$ is the Jacobian of the map at point $i$ (P1 of the companion page). The result is [DG eq. 15.3]:

$$\sum_{i=1}^{N_Q}\sum_{q=1}^{N}\phi_p(\mathbf x_i)\,w_iJ_i\,\phi_q(\mathbf x_i)\,\frac{du_q}{dt}=\sum_{i=1}^{N_Q}w_iJ_i\,\nabla\phi_p(\mathbf x_i)\cdot\mathbf H(\mathbf U^\delta_i)-\sum_{i=1}^{N_Q^\Gamma}\phi_p(\mathbf x_i^\Gamma)\,w_i^\Gamma J_i^\Gamma\,\hat H_{n,i}.$$

In your test files, the expansion is Modified_A with GaussLobattoLegendre points and $Q=P+2$ (NUMMODES="4", NUMPOINTS="5") [XML]. GLL with $Q$ points is exact up to degree $2Q-3=2P+1$ [KS 2.4.1]. Thus the mass matrix (degree $2P$) is exact on straight elements. The nonlinear flux is not exact (see Section 4.2).

1.4 Matrix form

Collect (15.3) for all $p$. The result is [DG eq. 15.4]:

$$\frac{d\mathbf u}{dt}=\mathbf M^{-1}\Big[\sum_{j=1}^{d}\mathbf B^{\mathsf T}\mathbf D_j^{\mathsf T}\Lambda(w J)\,\mathbf H_j-\mathbf B_\Gamma^{\mathsf T}\mathbf M_c^{\mathsf T}\Lambda(w^\Gamma J^\Gamma)\,\hat{\mathbf H}_n\Big]=\mathcal L_\delta(\mathbf u_\delta).$$

Quadrature choice in K&S and the aliasing condition

K&S Section 10.5.1.3 uses $Q=P+2$ Gauss–Lobatto points in the element interior and $Q=P+1$ Gauss points on each edge. The edge rule is then exact up to degree $2P+1$. The book states that this condition is necessary for the full accuracy $O(h^{P+1})$.

A flux $\mathbf F(\mathbf U)$ with $\mathbf U\in\mathbb P_P$ is a rational function for the Euler equations (division by $\rho$). No finite rule integrates it exactly. The User Guide gives a minimum number of points for consistent integration of the nonlinear terms [UG 9.4.3, eq. 9.13]:

$$Q_{\min}=P_{exp}+\frac{\max(2P_{exp},P_{geom})}{2}+\frac32 .$$

1.5 Time discretisation

Eq. (15.4) is a system of ODEs. A general linear method advances it [DG 4.12.1]. For a Runge–Kutta method with $s$ stages [DG eqs. 15.5–15.8]:

$$\mathbf s^{(i)}=\mathbf u^n+\Delta t\sum_{j=1}^{i-1}a_{ij}\mathcal L_\delta(\mathbf u^{(j)}),\qquad \mathbf u^{(i)}=\mathbf s^{(i)}+\Delta t\,a_{ii}\,\mathcal L_\delta(\mathbf u^{(i)}),\qquad \mathbf U^{n+1}=\mathbf U^n+\Delta t\sum_{i=1}^{s}b_i\,\mathcal L(\mathbf U^{(i)}).$$

For an explicit method, $a_{ii}=0$ and each stage is one evaluation of $\mathcal L_\delta$. For an implicit method ($a_{ii}\neq0$), each stage is a nonlinear system:

$$\mathbf N(\mathbf u^{(i)})=\mathbf u^{(i)}-\mathbf s^{(i)}-\Delta t\,a_{ii}\,\mathcal L_\delta(\mathbf u^{(i)})=0\quad(15.9).$$

Newton's method solves (15.9). Each Newton step solves $\frac{\partial\mathbf N}{\partial\mathbf v}\Delta\mathbf v=-\mathbf N(\mathbf v^k)$ (15.10) with restarted GMRES. GMRES needs only products of the Jacobian with a vector. A finite difference gives them [DG eq. 15.12]:

$$\frac{\partial\mathbf N}{\partial\mathbf u}(\mathbf u)\cdot\mathbf q\simeq\frac{\mathbf N(\mathbf u+\epsilon\mathbf q)-\mathbf N(\mathbf u)}{\epsilon}.$$

A block-relaxed Jacobi preconditioner $\mathbf P$ makes GMRES converge faster (15.13). The available schemes are [UG 9.3]:

LibUtilities in full: points, bases, managers, factories, time integration

Points. A PointsKey has the number of points and the point type (for example eGaussLobattoLegendre). A Points object holds the point positions m_points[3], the weights m_weights[3], the derivative matrices m_derivmatrix[3] and interpolation managers [DG 4.5.1, Fig. 4.1]. For Gauss-type points, the weights come from the Jacobi formulae of K&S App. B.

Basis. A BasisKey has the number of modes, the basis type (for example eModified_A) and a PointsKey. A Basis holds m_bdata (values $\phi_p(\xi_q)$) and m_dbdata (derivatives). The storage is one contiguous array: the fast index runs over the quadrature points, the slow index over the modes. This order matches the inner product, which is the most frequent kernel [DG 4.5.2, 5.2.5].

Managers. Many elements use the same basis at the same points. A manager receives a key. If it has the object, it returns a shared pointer. If not, it makes the object, keeps it and returns it. Thus each basis exists one time in memory. PointsManager and BasisManager are global singletons [DG 4.5].

Factory. The same mechanism selects classes from strings in the session file. A class registers a create function under a key (for example "Roe"). At run time the solver asks the factory for the key in SOLVERINFO. The solver does not need to know the class. This is how EQType, AdvectionType, UpwindType, DiffusionType and ShockCaptureType select objects [DG 3.5.2] [PLAN].

Time integration. All schemes are general linear methods with $r$ steps and $s$ stages [DG 4.12.1]:

$$\mathbf Y_i=\Delta t\sum_j a_{ij}\mathbf F_j+\sum_j u_{ij}\hat{\mathbf y}_j^{[n-1]},\qquad \hat{\mathbf y}_i^{[n]}=\Delta t\sum_j b_{ij}\mathbf F_j+\sum_j v_{ij}\hat{\mathbf y}_j^{[n-1]},\qquad \mathbf F_i=\hat f(\mathbf Y_i).$$

The solver gives the scheme two functions: the right-hand side (DefineOdeRhs) and the projection (DefineProjection). The implicit solver also gives DefineImplicitSolve [DG 4.12.6]. The scheme calls these functions at each stage. Thus the solver does not know which scheme it uses.

SpatialDomains in full: mesh, map and geometric factors

MeshGraphIO::Read reads the mesh file and makes a MeshGraph (since v5.7.0). The MeshGraph owns one Geometry object for each element, indexed by global ID [DG 6.2.5].

The map $\chi(\xi)$ from the reference element to the physical element is linear for straight segments and triangles, bilinear for straight quadrilaterals, and of higher order for curved elements. A curved edge adds an edge-mode term to the map, with coefficients from the curve points in the mesh file [DG 6.1.1].

GeomFactors holds, at each quadrature point, the Jacobian matrix $J_{ij}=\partial x_i/\partial\xi_j$, its inverse and its determinant. Derivatives use the chain rule $\partial/\partial x_i=(\partial\xi_j/\partial x_i)\,\partial/\partial\xi_j$. Integrals use $\det J$ [DG 6.1.2]. The inverse is calculated only at points, so on curved elements the integrals are approximate. The Guide states that over-integration can be necessary for highly curved elements. This applies to your NACA 0012 mesh near the leading edge.

StdRegions and LocalRegions in full: reference and physical elements

StdRegions defines operators on seven reference shapes: segment, triangle, quadrilateral, tetrahedron, hexahedron, prism, pyramid. All are subsets of $[-1,1]^d$. Collapsed coordinates map triangles and tetrahedra to tensor products, so that sum factorisation applies to all shapes [DG 5.1] [KS 3.2].

The class hierarchy is StdExpansion → StdExpansion1D/2D/3D → StdSegExp, StdQuadExp, … Data members: m_base (array of bases), m_ncoeffs, m_elmt_id, matrix managers [DG 5.2.1].

The modified basis (Type I) is [DG eq. 5.1] [KS 2.3.3]:

$$\phi_0=\frac{1-\xi}{2},\qquad \phi_1=\frac{1+\xi}{2},\qquad \phi_p=\frac{1-\xi}{2}\,\frac{1+\xi}{2}\,P^{1,1}_{p-2}(\xi),\;p\ge2 .$$

Nektar++ stores the two vertex modes first and the interior (bubble) modes after them. This order differs from K&S [DG 5.2.6]. At $\xi=-1$ only $\phi_0$ is nonzero; at $\xi=+1$ only $\phi_1$. Thus a 1D trace integral changes only the first two coefficients (see the trace in Section 3.6).

LocalRegions: Expansion is-a StdExpansion and has-a Geometry (m_geom) and GeomFactors (m_metricinfo) [DG 7.1–7.2]. It uses the reference operators with the geometric factors. Example: IProductWRTBase on a QuadExp multiplies by $w_iJ_i$, then calls the reference inner product.

Collections in full: one matrix product instead of many

A loop over elements that applies the same operator to each element is a loop of level-2 BLAS calls. If all elements in a group have the same shape, basis, order and points, the loop is one level-3 call: one basis matrix times a matrix whose columns are the coefficients of all elements. Collections makes these groups. There are reference-space collections and physical-space collections [DG 8.1].

The solver does not call Collections. ExpList::BwdTrans, IProductWRTBase, IProductWRTDerivBase and PhysDeriv use them internally. This is the origin of the exponent $b$ in your cost model: sum-factorised and dense-matrix operators scale differently with $P$.

MultiRegions in full: fields, coefficients, physical values and the trace

ExpList is a list of local expansions. DisContField is-a ExpList with no continuity between elements and with a trace: an ExpList of one dimension less that holds the element boundaries. ContField adds $C^0$ continuity and is not used by this solver [DG 9.1–9.2, Fig. 9.3].

Each field holds two arrays:

  • m_coeffs: the modal coefficients of all elements, $\sum_eN^e$ values.
  • m_phys: the values at the quadrature points of all elements, $\sum_eQ^e$ values.

BwdTrans goes from coefficients to physical values ($\mathbf u=\mathbf B\hat{\mathbf u}$). FwdTrans goes back by $L^2$ projection ($\hat{\mathbf u}=\mathbf M^{-1}\mathbf B^{\mathsf T}\Lambda(wJ)\mathbf u$).

Trace operations:

  • GetFwdBwdTracePhys(phys, Fwd, Bwd): the values on each trace point from the two adjacent elements. On a domain boundary, the boundary-condition objects fill the exterior value.
  • AddTraceIntegral(Fn, coeffs): adds $\int_{\Gamma^e}\phi_p\,\hat H_n$ to each element, with the sign of the element normal.
  • MultiplyByElmtInvMass(in, out): applies $\mathbf M_e^{-1}$ element by element. In DG the mass matrix is block diagonal, so no global solve is necessary.
SolverUtils and the solver in full: class structure (Dev Guide Fig. 15.1)

Inheritance chain (is-a): EulerCFE / NavierStokesCFE → CompressibleFlowSystem → AdvectionSystem → UnsteadySystem → EquationSystem [DG Fig. 15.1].

Members (has-a) that the equation system makes from factories [DG 15.4]:

  • m_advObject: Advection (for example AdvectionWeakDG), with a pointer to the flux function $\mathbf F$ and to the Riemann solver m_riemann.
  • m_diffusion: Diffusion (DiffusionLDGNS or DiffusionIP), with a pointer to the viscous flux $\mathbf G$. Only for Navier–Stokes.
  • m_artificialDiffusion: ArtificialDiffusion, for ShockCaptureType = NonSmooth.
  • m_bndConds: one CFSBndCond per boundary region.
  • m_forcing: list of Forcing objects.
  • m_intScheme: the TimeIntegrationScheme.

The equation system gives the flux functions and the physical models. The library operators calculate $\nabla\cdot\mathbf F$ and $\nabla\cdot\mathbf G$. A function pointer links the spatial operator $\mathcal L_\delta$ to the time integration [DG 15.4].

For the implicit solver, more objects are made: the Newton solver NekNonlinSysNewton, the GMRES solver NekLinSysIterGMRES and the preconditioner PrecondCfsBRJ [DG Fig. 15.2].

(b) Diffusion (LDGNS) and artificial diffusion

LDG writes the viscous term as a first-order system [KS 10.5.1.2]. Step 1 calculates the auxiliary variable $\mathbf q=\nabla\mathbf w$ (primitive variables $\mathbf w$) in weak form with a trace value $\hat{\mathbf w}$. Step 2 calculates $\mathbf G(\mathbf w,\mathbf q)$ at the quadrature points. Step 3 integrates $\nabla\cdot\mathbf G$ in weak form with a trace flux $\hat{\mathbf G}$ that has a penalty term:

$$(\phi,\mathbf q)_e=-(\nabla\phi,\mathbf w)_e+\langle\phi,\hat{\mathbf w}\,\mathbf n\rangle_e,\qquad (\phi,\partial_t\mathbf U)_e\mathrel{+}=-(\nabla\phi,\mathbf G)_e+\langle\phi,\hat{\mathbf G}\cdot\mathbf n\rangle_e .$$

The LDGNS penalty is inversely proportional to the element size. It is proportional to the local viscosity (momentum) and to the thermal conductivity (energy), times LDGNSc11 (default 1) [UG 9.3]. The functions are DiffuseCalcDerivative, DiffuseVolumeFlux, DiffuseTraceFlux, and for IP also AddDiffusionSymmFluxToCoeff [DG 15.2].

NonSmooth artificial diffusion uses the same LDG machinery on the conserved variables, with the flux $\varepsilon(\mathbf x)\nabla\mathbf U$ [PLAN]. Section 4.3 gives $\varepsilon$.

3.5 Time step

With CFL in PARAMETERS (your isentropic-vortex cases use CFL = 0.02, TimeStep = 0) [XML], the solver calculates $\Delta t$ from an element estimate. The bound has the form of [KS 6.3.1, eq. 6.3.2]:

$$\Delta t\le\frac{\alpha_{im}}{C(\mathbf V,h)\,P^2},\qquad \lambda_{\max}\approx c_\lambda\max|\mathbf V^{st}|\,P^2,$$

where $\mathbf V^{st}$ is the velocity mapped to the reference element and $c_\lambda\approx0.2$ [KS 6.3.1]. For the Euler equations the speed is $|\mathbf u|+c$. The example program in Section 3.6 uses $\Delta t=\text{CFL}\cdot h/((2P+1)\lambda_{\max})$, the form that your cost notes give. The exact element formula is in GetTimeStep [SRC?].

4. Stabilisation and the SVV insertion point

A high-order DG solution of a transonic flow has two problems: Gibbs oscillations at shocks, and aliasing from the nonlinear fluxes when the mesh does not resolve all scales [KS 6.5]. CompressibleFlowSolver has five mechanisms against them. None of them is SVV.

4.1 Riemann-solver dissipation

The numerical flux adds dissipation proportional to the jump at the interface. For Lax–Friedrichs:

$$\hat F_n=\tfrac12\big(\mathbf F(\mathbf U^-)+\mathbf F(\mathbf U^+)\big)\cdot\mathbf n-\tfrac12\lambda_{\max}(\mathbf U^+-\mathbf U^-).$$

For Roe, the dissipation is $\tfrac12|\mathbf A|(\mathbf U^+-\mathbf U^-)$ with $|\mathbf A|=\mathbf R|\mathbf D|\mathbf L$, the characteristic decomposition of K&S App. E. The jump is small for resolved modes and large for unresolved modes. Thus upwind DG has a built-in dissipation of high modes. Your notes state that the solver has no turbulence closure: it is DNS when resolved and implicit LES when under-resolved, with dissipation from this flux, from AV and from filtering.

4.2 Dealiasing

Aliasing occurs when nonlinear terms are calculated with too few quadrature points [KS 2.4.1.2]. Two sources exist: the PDE (fluxes) and the geometry (curved elements). The User Guide gives $Q_{\min}$ (eq. 9.13, Section 1.4 above). You increase NUMPOINTS in the expansion to apply it. The keyword SPECTRALHPDEALIASING exists in the incompressible solver [UG 11.3.5.1]. Your plan lists it as a baseline key [PLAN].

4.3 NonSmooth artificial viscosity (Persson–Peraire)

The Euler system gets a Laplacian term $\nabla\cdot(\varepsilon\nabla\mathbf U)$ on the right side. $\varepsilon$ is constant in each element and discontinuous between elements [UG 9.4.1.1]:

$$\varepsilon=\varepsilon_0\,\frac{h}{p}\,\lambda_{\max}\,S_\varepsilon\quad(9.8).$$

The modal sensor compares the full and truncated expansions of the density [UG eqs. 9.9–9.11]:

$$s_e=\log_{10}\frac{\langle q-\tilde q,\,q-\tilde q\rangle}{\langle q,q\rangle},\qquad q=\sum_{i=1}^{N(P)}\hat q_i\phi_i,\quad \tilde q=\sum_{i=1}^{N(P-1)}\hat q_i\phi_i,$$

$$S_\varepsilon=\begin{cases}0 & s_e<s_0-\kappa\\ \tfrac12\Big(1+\sin\dfrac{\pi(s_e-s_0)}{2\kappa}\Big) & |s_e-s_0|\le\kappa\\ 1 & s_e>s_0+\kappa\end{cases},\qquad s_0=s_\kappa-4.25\log_{10}p .$$

Parameters: Skappa ($s_\kappa$, example −1.3), Kappa ($\kappa$, 0.2), mu0 ($\varepsilon_0$, 1.0). This option exists only for the explicit solvers [UG 9.3, 9.4.1]. The sensor measures the energy in the highest mode set. SVV acts on the same high modes but without a switch.

4.4 Physical artificial viscosity

ShockCaptureType = Physical adds the artificial viscosity to the physical viscosity. It exists only for the Navier–Stokes systems (explicit and implicit). The sensor is Modal (default) or Dilatation. DucrosSensor = On removes the viscosity where vorticity is large. Smoothing = C0 makes $\varepsilon$ continuous [UG 9.3]. Your shock-tube tests use Physical + Dilatation + DucrosSensor with IP diffusion [XML].

4.5 Exponential filter

The filter multiplies the modal coefficients of each element by a factor that decreases with the mode number. It is applied in DoOdeProjection, after the stage values are known [PLAN]. The keys are ExponentialFiltering, FilterAlpha, FilterExponent, FilterCutoff [PLAN]. The usual form is

$$\sigma(\eta)=\begin{cases}1&\eta\le\eta_c\\ \exp\!\Big(-\alpha\Big(\dfrac{\eta-\eta_c}{1-\eta_c}\Big)^{s}\Big)&\eta>\eta_c\end{cases},\qquad \eta=\frac{k}{P}.$$

Check the exact expression in StdExpansion::ExponentialFilter [SRC?]. A filter applied at each stage acts as a dissipation whose strength depends on $\Delta t$ (the number of applications per unit time). K&S Section 6.5.1 shows that the Vandeven filter recovers accuracy away from a discontinuity, but gives no improvement for linear advection of a square wave.

4.7 SVV operator

Tadmor's SVV adds a viscosity that acts only on high modes [KS 6.5.2, eq. 6.5.8]:

$$\partial_t\mathbf U+\nabla\cdot\mathbf F=\nabla\cdot\big(\varepsilon_{SVV}\,\mathcal Q[\nabla\mathbf U]\big),\qquad \widehat{(\mathcal Q v)}_k=\hat Q_k\,\hat v_k .$$

$\hat Q_k$ is applied to the modal coefficients in an orthogonal basis of each element. The exponential kernel of your skeleton (SVVExpKernel::v_GetKernel) is

$$\hat Q_k=\begin{cases}0 & k\le M\\ \exp\!\Big(-\dfrac{(k-P)^2}{(k-M)^2}\Big)&k>M\end{cases},\qquad M=\lfloor c_{cut}\,P\rfloor .$$

In weak DG form the term uses the LDG steps of Section 3.4 (b), with the kernel applied to the auxiliary variable:

  1. $\mathbf q=\nabla\mathbf U$ in weak form (trace value $\hat{\mathbf U}$).
  2. For each element: transform $\mathbf q$ to the orthogonal basis, multiply mode $k$ by $\varepsilon_{SVV}\hat Q_k$, transform back. The result is $\mathbf G_{SVV}$.
  3. $(\phi,\partial_t\mathbf U)\mathrel{+}=-(\nabla\phi,\mathbf G_{SVV})+\langle\phi,\hat{\mathbf G}_{SVV}\cdot\mathbf n\rangle$.

This is the change that your plan states: "instead of viscousTensor = mu(x)·qfield, per element FwdTrans orthogonal of qfield $\rightarrow$ scale mode $k$ by $\varepsilon\,\hat Q_k$ $\rightarrow$ BwdTrans" [PLAN].

// ---------------- LibUtilities::Foundations (Points, Basis) ----------------
double Jacobi(int n, double a, double b, double x)            // P_n^{a,b}(x)
{
    if (n == 0) return 1.0;
    double p0 = 1.0, p1 = 0.5 * (a - b + (a + b + 2) * x);
    for (int k = 2; k <= n; ++k)
    {
        double c = 2 * k + a + b;
        double a1 = 2 * k * (k + a + b) * (c - 2);
        double a2 = (c - 1) * (a * a - b * b);
        double a3 = (c - 2) * (c - 1) * c;
        double a4 = 2 * (k + a - 1) * (k + b - 1) * c;
        double p2 = ((a2 + a3 * x) * p1 - a4 * p0) / a1;
        p0 = p1; p1 = p2;
    }
    return p1;
}
double dJacobi(int n, double a, double b, double x)
{
    return n == 0 ? 0.0 : 0.5 * (n + a + b + 1) * Jacobi(n - 1, a + 1, b + 1, x);
}

// Gauss-Lobatto-Legendre points and weights (eGaussLobattoLegendre), Q points
void GLL(int Q, Vec &z, Vec &w)
{
    int N = Q - 1;
    z.assign(Q, 0); w.assign(Q, 0);
    for (int i = 0; i < Q; ++i)
    {
        double x = -std::cos(PI * i / N);
        for (int it = 0; it < 100; ++it)
        {
            double PN = Jacobi(N, 0, 0, x), PNm1 = Jacobi(N - 1, 0, 0, x);
            double dx = (x * PN - PNm1) / (Q * PN);
            x -= dx;
            if (std::abs(dx) < 1e-16) break;
        }
        z[i] = x;
        double PN = Jacobi(N, 0, 0, x);
        w[i] = 2.0 / (N * (N + 1) * PN * PN);
    }
}

// Modified_A basis: phi_0 = (1-x)/2, phi_1 = (1+x)/2, phi_p = (1-x)(1+x)/4 P^{1,1}_{p-2}
double phi(int p, double x)
{
    if (p == 0) return 0.5 * (1 - x);
    if (p == 1) return 0.5 * (1 + x);
    return 0.25 * (1 - x) * (1 + x) * Jacobi(p - 2, 1, 1, x);
}
double dphi(int p, double x)
{
    if (p == 0) return -0.5;
    if (p == 1) return 0.5;
    return -0.5 * x * Jacobi(p - 2, 1, 1, x) + 0.25 * (1 - x * x) * dJacobi(p - 2, 1, 1, x);
}

Mat inverse(Mat M)
{
    int N = M.size();
    Mat I(N, Vec(N, 0));
    for (int i = 0; i < N; ++i) I[i][i] = 1;
    for (int k = 0; k < N; ++k)
    {
        int p = k;
        for (int r = k + 1; r < N; ++r) if (std::abs(M[r][k]) > std::abs(M[p][k])) p = r;
        std::swap(M[k], M[p]); std::swap(I[k], I[p]);
        double d = M[k][k];
        for (int j = 0; j < N; ++j) { M[k][j] /= d; I[k][j] /= d; }
        for (int r = 0; r < N; ++r)
        {
            if (r == k) continue;
            double m = M[r][k];
            for (int j = 0; j < N; ++j) { M[r][j] -= m * M[k][j]; I[r][j] -= m * I[k][j]; }
        }
    }
    return I;
}

        return r;
    }
    Vec FwdTrans(const Vec &u) const { return MultiplyByElmtInvMass(IProductWRTBase(u)); }
};

// ---------------- MultiRegions::DisContField (1D, uniform mesh) ----------------
struct DisContField
{
    int ne; bool periodic; double x0, h;
    SegExp exp;
    DisContField(int ne_, int P, double a, double b, bool per)
        : ne(ne_), periodic(per), x0(a), h((b - a) / ne_), exp(P, P + 2, (b - a) / ne_) {}
    int nTrace() const { return periodic ? ne : ne + 1; }
    double xq(int e, int q) const { return x0 + h * e + exp.J * (exp.z[q] + 1); }

    // trace k sits at x0 + k h; Fwd = left element (normal +x points out of it), Bwd = right element
    void GetFwdBwdTracePhys(const std::vector<Vec> &phys, Vec &Fwd, Vec &Bwd) const
    {
        int nt = nTrace(), Q = exp.nq;
        Fwd.assign(nt, 0); Bwd.assign(nt, 0);
        for (int k = 0; k < nt; ++k)
        {
            int eL = k - 1, eR = k;
            if (periodic) { eL = (k - 1 + ne) % ne; eR = k % ne; }
            if (eL < 0) eL = -1;
            if (eR >= ne) eR = -1;
            Fwd[k] = eL >= 0 ? phys[eL][Q - 1] : phys[eR][0];   // outflow (copy) boundary
            Bwd[k] = eR >= 0 ? phys[eR][0] : phys[eL][Q - 1];
        }
    }
    // adds the trace integral <phi, Fn n>: +phi(+1)Fn at right end, -phi(-1)Fn at left end
    void AddTraceIntegral(const Vec &Fn, std::vector<Vec> &coeffs) const
    {
        int nt = nTrace();
        for (int e = 0; e < ne; ++e)
        {
            int kL = e, kR = periodic ? (e + 1) % nt : e + 1;
            coeffs[e][1] += Fn[kR];   // Modified_A: only phi_1 is nonzero at xi = +1
            coeffs[e][0] -= Fn[kL];   // only phi_0 is nonzero at xi = -1
        }
    }
};

// ---------------- CompressibleFlowSolver (EulerCFE) ----------------
using Field = std::vector<std::vector<Vec>>;     // [variable][element][point or mode]
struct EulerCFE
{
    DisContField f;
    std::string upwind;
    double svvCoeff = 0, svvCutoff = 0.5;
    bool trace = false;

    EulerCFE(int ne, int P, double a, double b, bool per, std::string up)
        : f(ne, P, a, b, per), upwind(up) {}

    static double pressure(double r, double ru, double E) { return (GAMMA - 1) * (E - 0.5 * ru * ru / r); }

    // GetFluxVector: F(U) at every quadrature point
    Field GetFluxVector(const Field &U) const
    {
        Field F = U;
        for (int e = 0; e < f.ne; ++e)
            for (int q = 0; q < f.exp.nq; ++q)
            {
                double r = U[0][e][q], ru = U[1][e][q], E = U[2][e][q], u = ru / r, p = pressure(r, ru, E);
                F[0][e][q] = ru; F[1][e][q] = ru * u + p; F[2][e][q] = u * (E + p);
            }
        return F;
    }
    // RiemannSolver::Solve on the trace (1D: normal = +x, no rotation needed)
    void RiemannSolve(const std::vector<Vec> &Fwd, const std::vector<Vec> &Bwd, std::vector<Vec> &Fn) const
    {
        int nt = Fwd[0].size();
        Fn.assign(3, Vec(nt, 0));
        for (int k = 0; k < nt; ++k)
        {
            double L[3] = {Fwd[0][k], Fwd[1][k], Fwd[2][k]}, R[3] = {Bwd[0][k], Bwd[1][k], Bwd[2][k]};
            double uL = L[1] / L[0], pL = pressure(L[0], L[1], L[2]), cL = std::sqrt(GAMMA * pL / L[0]);
            double uR = R[1] / R[0], pR = pressure(R[0], R[1], R[2]), cR = std::sqrt(GAMMA * pR / R[0]);
            double FL[3] = {L[1], L[1] * uL + pL, uL * (L[2] + pL)};
            double FR[3] = {R[1], R[1] * uR + pR, uR * (R[2] + pR)};
            if (upwind == "LaxFriedrichs")
            {
                double lam = std::max(std::abs(uL) + cL, std::abs(uR) + cR);
                for (int i = 0; i < 3; ++i) Fn[i][k] = 0.5 * (FL[i] + FR[i]) - 0.5 * lam * (R[i] - L[i]);
                continue;
            }
            // Roe: F = (FL+FR)/2 - 1/2 sum |lambda_j| alpha_j r_j   (K&S App. E characteristic split)
            double sL = std::sqrt(L[0]), sR = std::sqrt(R[0]);
            double u = (sL * uL + sR * uR) / (sL + sR);
            double H = (sL * (L[2] + pL) / L[0] + sR * (R[2] + pR) / R[0]) / (sL + sR);
            double c = std::sqrt((GAMMA - 1) * (H - 0.5 * u * u));
            double dr = R[0] - L[0], du = uR - uL, dp = pR - pL, rho = sL * sR;
            double a1 = (dp - rho * c * du) / (2 * c * c), a2 = dr - dp / (c * c), a3 = (dp + rho * c * du) / (2 * c * c);
            double l1 = std::abs(u - c), l2 = std::abs(u), l3 = std::abs(u + c);
            double r1[3] = {1, u - c, H - u * c}, r2[3] = {1, u, 0.5 * u * u}, r3[3] = {1, u + c, H + u * c};
            for (int i = 0; i < 3; ++i)
                Fn[i][k] = 0.5 * (FL[i] + FR[i]) - 0.5 * (l1 * a1 * r1[i] + l2 * a2 * r2[i] + l3 * a3 * r3[i]);
        }
    }
    void print(const char *name, const Vec &v) const
    {
        if (!trace) return;
        std::printf("%-34s", name);
        for (double x : v) std::printf(" %10.6f", x);
        std::printf("\n");
    }
    // AdvectionWeakDG::Advect -> returns div(F) in weak DG form, in physical space
    Field DoAdvection(const Field &U) const
    {
        int nv = 3, ne = f.ne;
        Field F = GetFluxVector(U);                                       // (1) volume flux
        std::vector<std::vector<Vec>> c(nv, std::vector<Vec>(ne));
        for (int i = 0; i < nv; ++i)
            for (int e = 0; e < ne; ++e) c[i][e] = f.exp.IProductWRTDerivBase(F[i][e]);   // (2)
        std::vector<Vec> Fwd(nv), Bwd(nv), Fn;
        for (int i = 0; i < nv; ++i) f.GetFwdBwdTracePhys(U[i], Fwd[i], Bwd[i]);         // (3)
        RiemannSolve(Fwd, Bwd, Fn);                                                     // (4)
        if (trace)
        {
            for (int e = 0; e < ne; ++e) { print("rho phys, elmt", U[0][e]); }
            for (int e = 0; e < ne; ++e) print("F_rho = rho u at quad pts", F[0][e]);
            for (int e = 0; e < ne; ++e) print("IProductWRTDerivBase(F_rho)", c[0][e]);
            print("Fwd rho (trace)", Fwd[0]); print("Bwd rho (trace)", Bwd[0]); print("Fn rho (Riemann)", Fn[0]);
        }
        for (int i = 0; i < nv; ++i)
            for (int e = 0; e < ne; ++e) for (double &x : c[i][e]) x = -x;                // (5) Neg
        for (int i = 0; i < nv; ++i) f.AddTraceIntegral(Fn[i], c[i]);                   // (6)
        if (trace) for (int e = 0; e < ne; ++e) print("-IProd + AddTraceIntegral", c[0][e]);
        Field out(nv, std::vector<Vec>(ne));
        for (int i = 0; i < nv; ++i)
            for (int e = 0; e < ne; ++e)
                out[i][e] = f.exp.BwdTrans(f.exp.MultiplyByElmtInvMass(c[i][e]));        // (7)(8)
        if (trace) for (int e = 0; e < ne; ++e) print("div F after InvMass + BwdTrans", out[0][e]);
        return out;
    }

    // Orthonormal-Legendre modal filter Q applied element by element (SVV kernel)
    Vec ApplyKernel(const Vec &u) const
    {
        int Q = f.exp.nq, P = f.exp.ncoeffs - 1, M = int(svvCutoff * P);
        Vec out(Q, 0);
        for (int k = 0; k <= P; ++k)
        {
            if (k <= M) continue;
            double kern = std::exp(-double((k - P) * (k - P)) / double((k - M) * (k - M)));
            double uk = 0;
            for (int q = 0; q < Q; ++q) uk += f.exp.w[q] * Jacobi(k, 0, 0, f.exp.z[q]) * u[q];
            uk *= (2 * k + 1) / 2.0;
            for (int q = 0; q < Q; ++q) out[q] += kern * uk * Jacobi(k, 0, 0, f.exp.z[q]);
        }
        return out;
    }
    // weak derivative with a central trace value (LDG/BR1 first step)
    std::vector<Vec> WeakDeriv(const std::vector<Vec> &u, bool zeroWallFlux = false) const
    {
        int ne = f.ne;
        Vec Fwd, Bwd; f.GetFwdBwdTracePhys(u, Fwd, Bwd);
        Vec avg(Fwd.size()); for (size_t k = 0; k < avg.size(); ++k) avg[k] = 0.5 * (Fwd[k] + Bwd[k]);
        if (zeroWallFlux && !f.periodic) { avg[0] = 0; avg[ne] = 0; }   // no SVV flux through the domain ends
        std::vector<Vec> c(ne);
        for (int e = 0; e < ne; ++e) { c[e] = f.exp.IProductWRTDerivBase(u[e]); for (double &x : c[e]) x = -x; }
        f.AddTraceIntegral(avg, c);
        std::vector<Vec> q(ne);
        for (int e = 0; e < ne; ++e) q[e] = f.exp.BwdTrans(f.exp.MultiplyByElmtInvMass(c[e]));
        return q;
    }
    // SVV term d/dx( eps Q[dU/dx] ), eps = SVVDiffCoeff * h/P * lambda_max
    Field DoSVV(const Field &U, double lam) const
    {
        Field out(3, std::vector<Vec>(f.ne));
        double eps = svvCoeff * f.h / (f.exp.ncoeffs - 1) * lam;
        for (int i = 0; i < 3; ++i)
        {
            std::vector<Vec> q = WeakDeriv(U[i]);
            for (int e = 0; e < f.ne; ++e) { q[e] = ApplyKernel(q[e]); for (double &x : q[e]) x *= eps; }
            out[i] = WeakDeriv(q, true);
        }
        return out;
    }
    double MaxSpeed(const Field &U) const
    {
        double lam = 0;
        for (int e = 0; e < f.ne; ++e)
            for (int q = 0; q < f.exp.nq; ++q)
            {
                double r = U[0][e][q], u = U[1][e][q] / r, p = pressure(r, U[1][e][q], U[2][e][q]);
                lam = std::max(lam, std::abs(u) + std::sqrt(GAMMA * std::max(p, 1e-14) / r));
            }
        return lam;
    }
    // CompressibleFlowSystem::DoOdeRhs
    Field DoOdeRhs(const Field &U) const
    {
        Field out = DoAdvection(U);
        for (auto &v : out) for (auto &e : v) for (double &x : e) x = -x;               // Vmath::Neg
        if (svvCoeff > 0)
        {
            Field s = DoSVV(U, MaxSpeed(U));
            for (int i = 0; i < 3; ++i) for (int e = 0; e < f.ne; ++e)
                for (int q = 0; q < f.exp.nq; ++q) out[i][e][q] += s[i][e][q];
        }
        if (trace) for (int e = 0; e < f.ne; ++e) print("d rho/dt = DoOdeRhs", out[0][e]);
        return out;
    }
    // DoOdeProjection: DG keeps physical values as they are (BCs live in the trace here)
    Field DoOdeProjection(const Field &U) const { return U; }

    void RK4(Field &U, double dt) const
    {
        auto axpy = [](const Field &a, const Field &b, double s) {
            Field r = a;
            for (size_t i = 0; i < r.size(); ++i) for (size_t e = 0; e < r[i].size(); ++e)
                for (size_t q = 0; q < r[i][e].size(); ++q) r[i][e][q] += s * b[i][e][q];
            return r; };
        Field k1 = DoOdeRhs(DoOdeProjection(U));
        Field k2 = DoOdeRhs(DoOdeProjection(axpy(U, k1, dt / 2)));
        Field k3 = DoOdeRhs(DoOdeProjection(axpy(U, k2, dt / 2)));
        Field k4 = DoOdeRhs(DoOdeProjection(axpy(U, k3, dt)));
        for (size_t i = 0; i < U.size(); ++i) for (size_t e = 0; e < U[i].size(); ++e)
            for (size_t q = 0; q < U[i][e].size(); ++q)
                U[i][e][q] += dt / 6 * (k1[i][e][q] + 2 * k2[i][e][q] + 2 * k3[i][e][q] + k4[i][e][q]);
    }
    // SetInitialConditions: evaluate, then FwdTrans + BwdTrans (project onto the polynomial space)
    Field SetInitialConditions(std::function<void(double, double &, double &, double &)> ic) const
    {
        Field U(3, std::vector<Vec>(f.ne, Vec(f.exp.nq)));
        for (int e = 0; e < f.ne; ++e)
        {
            for (int q = 0; q < f.exp.nq; ++q)
            {
                double r, u, p; ic(f.xq(e, q), r, u, p);
                U[0][e][q] = r; U[1][e][q] = r * u; U[2][e][q] = p / (GAMMA - 1) + 0.5 * r * u * u;
            }
            for (int i = 0; i < 3; ++i) U[i][e] = f.exp.BwdTrans(f.exp.FwdTrans(U[i][e]));
        }
        return U;
    }
    double GetTimeStep(const Field &U, double cfl) const
    {
        int P = f.exp.ncoeffs - 1;
        double lam = MaxSpeed(U), dt = cfl * f.h / ((2 * P + 1) * lam);
        double eps = svvCoeff * f.h / P * lam;            // explicit viscous limit for the SVV term
        if (eps > 0) dt = std::min(dt, cfl * f.h * f.h / (eps * std::pow(P + 1, 4)));
        return dt;
    }
};

int main(int argc, char **argv)
{
    std::string mode = argc > 1 ? argv[1] : "trace";
    auto wave = [](double x, double &r, double &u, double &p) { r = 1 + 0.2 * std::sin(PI * x); u = 1; p = 1; };

    if (mode == "trace")                          // one DoOdeRhs, 2 elements, P = 2, Q = 4
    {
        EulerCFE s(2, 2, -1, 1, true, "LaxFriedrichs");
        s.trace = true;
        Field U = s.SetInitialConditions(wave);
        Field R = s.DoOdeRhs(U);
        for (int e = 0; e < 2; ++e)
        {
            Vec ex(s.f.exp.nq);
            for (int q = 0; q < s.f.exp.nq; ++q) ex[q] = -0.2 * PI * std::cos(PI * s.f.xq(e, q));
            s.print("exact -d(rho u)/dx", ex);
        }
        Vec xs; for (int e = 0; e < 2; ++e) for (int q = 0; q < s.f.exp.nq; ++q) xs.push_back(s.f.xq(e, q));
        s.print("x (quadrature points)", xs);
        return 0;
    }
    if (mode == "conv")                           // smooth density wave, t = 1 (half period)
    {
        for (std::string up : {"LaxFriedrichs", "Roe"})
            for (int P = 1; P <= 5; ++P)
            {
                std::printf("%-13s P=%d", up.c_str(), P);
                for (int ne : {8, 16})
                {
                    EulerCFE s(ne, P, -1, 1, true, up);
                    Field U = s.SetInitialConditions(wave);
                    double T = 1.0, dt = s.GetTimeStep(U, 0.2);
                    int n = std::ceil(T / dt); dt = T / n;
                    for (int k = 0; k < n; ++k) s.RK4(U, dt);
                    double err = 0;
                    for (int e = 0; e < ne; ++e) for (int q = 0; q < s.f.exp.nq; ++q)
                        err = std::max(err, std::abs(U[0][e][q] - (1 + 0.2 * std::sin(PI * (s.f.xq(e, q) - T)))));
                    std::printf("  Ne=%2d err=%.3e", ne, err);
                }
                std::printf("\n");
            }
        return 0;
    }
    if (mode == "profile")                       // rho(x) at t = 0.2 for SVVDiffCoeff = 0.5
    {
        auto sod = [](double x, double &r, double &u, double &p) {
            if (x < 0.5) { r = 1; u = 0; p = 1; } else { r = 0.125; u = 0; p = 0.1; } };
        EulerCFE s(40, 4, 0, 1, false, "Roe");
        s.svvCoeff = 0.5;
        Field U = s.SetInitialConditions(sod);
        double t = 0;
        while (t < 0.2 - 1e-12) { double dt = std::min(s.GetTimeStep(U, 0.1), 0.2 - t); s.RK4(U, dt); t += dt; }
        for (int e = 0; e < 40; ++e) for (int q = 0; q < s.f.exp.nq; ++q) std::printf("%.5f %.5f\n", s.f.xq(e, q), U[0][e][q]);
        return 0;
    }
    if (mode == "sod")                            // Sod tube, P = 4, 40 elements, t = 0.2
    {
        auto sod = [](double x, double &r, double &u, double &p) {
            if (x < 0.5) { r = 1; u = 0; p = 1; } else { r = 0.125; u = 0; p = 0.1; } };
        for (double c : {0.0, 0.25, 0.5, 1.0})
        {
            EulerCFE s(40, 4, 0, 1, false, "Roe");
            s.svvCoeff = c;
            Field U = s.SetInitialConditions(sod);
            double t = 0; bool ok = true;
            while (t < 0.2 - 1e-12)
            {
                double dt = std::min(s.GetTimeStep(U, 0.1), 0.2 - t);
                s.RK4(U, dt); t += dt;
                for (auto &el : U[0]) for (double r : el) if (!std::isfinite(r) || r <= 0) ok = false;
                if (!ok) break;
            }
            double rmax = 0, rmin = 1e9, tv = 0, prev = U[0][0][0];
            for (int e = 0; e < 40; ++e) for (int q = 0; q < s.f.exp.nq; ++q)
            {
                double r = U[0][e][q];
                rmax = std::max(rmax, r); rmin = std::min(rmin, r); tv += std::abs(r - prev); prev = r;
            }
            if (ok) std::printf("SVVDiffCoeff=%.2f  t=0.2  max rho=%.4f  min rho=%.4f  TV(rho)=%.4f\n", c, rmax, rmin, tv);
            else    std::printf("SVVDiffCoeff=%.2f  failed (non-finite state) at t=%.4f\n", c, t);
        }
        return 0;
    }
